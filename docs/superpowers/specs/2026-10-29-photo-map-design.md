# photo-map 設計書（第1弾）

- 作成日：2026-10-29
- 対象：第1弾（全3段階のうち1段階目）

## 1. 目的

iPhone の写真を使い、出かけた先・旅を地図で振り返る。行った場所を地図で整理する。

## 2. 前提・制約

| 項目 | 内容 |
|---|---|
| 使う人 | 本人1人（共有はしない） |
| 使う端末 | iPhone の Safari（ホーム画面に追加して使う） |
| 費用 | ずっと無料 |
| 形式 | Webアプリ（ブラウザで動くアプリ） |
| 置き場所 | GitHub Pages（`architect0417.github.io/photo-map`） |
| 写真の扱い | 写真はネットに送らない。iPhone の中だけで処理・保存する |
| 公開範囲 | プログラムは公開される。写真・位置情報は公開されない |

## 3. 段階ごとの機能

| 段階 | 機能 |
|---|---|
| 第1弾（本書） | 写真を地図に表示／場所を入力して周辺に拡大・周辺の写真を日時つきで一覧／撮影日時の表示／旅アルバム（日付ごと）／ルート表示（その日の写真を時間順に線でつなぐ） |
| 第2弾 | 移動距離・時間の表示（日付一覧に「〇km・〇時〜〇時」を追加） |
| 第3弾 | ルート再生（日付を選んだときに「▶再生」ボタンを追加） |

第1弾の時点で、写真を「撮影日ごと・時間順」に整理する作りにする。第2弾・第3弾は画面を作り直さず、表示やボタンを足すだけで済むようにする。

## 4. 画面のつくり

```
┌──────────────────────────────┐
│ [場所を入力 例:本部町]   [＋写真] │ ← 上：検索と写真追加
├──────────────────────────────┤
│   地図（写真が小さいピンで並ぶ）       │ ← 中央：地図
│      ●───●───●  ← その日のルート      │
├──────────────────────────────┤
│ 10/29 12枚 │ 10/12 8枚 │ …            │ ← 下：旅アルバム（日付ごと）
└──────────────────────────────┘
```

| 操作 | 動き |
|---|---|
| 場所を入力 | 地図がその周辺に拡大。近くの写真を撮影日時つきで一覧表示 |
| 下の日付を押す | その日の写真を時間順に線でつなぎ、地図をその範囲に合わせて拡大 |
| ピンを押す | 写真を大きく表示し、撮影日時を出す |
| ＋写真 | iPhone の写真をまとめて選んで追加 |

## 5. 使うもの（すべて無料）

| 用途 | 使うもの |
|---|---|
| 地図 | OpenStreetMap ＋ Leaflet（地図を表示する部品） |
| 地名の検索 | OpenStreetMap の検索サービス（Nominatim） |
| 写真の位置・日時の読み取り | exifr（写真の情報を読む部品） |
| 写真データの保存 | Safari の中の保存場所（IndexedDB） |

## 6. データの流れ

1. 写真をまとめて選ぶ
2. 写真から位置・撮影日時を読み取る
3. 地図ピン用（小）と拡大表示用（中）の画像を作る。元の写真は保存しない
4. Safari の中に保存する
5. 撮影日ごとにまとめ、時間順に並べる

### 1枚の写真で保存する項目

| 項目 | 内容 |
|---|---|
| ID | 撮影日時＋位置＋ファイル名から作る（重複判定に使う） |
| 撮影日時 | 写真の情報から読む |
| 緯度・経度 | 写真の情報から読む |
| ファイル名 | 元のファイル名 |
| 小さい画像 | 地図のピン用 |
| 中くらいの画像 | 拡大表示用 |

### 決めごと

| 項目 | 決め方 |
|---|---|
| 同じ写真の判定 | 撮影日時＋位置＋ファイル名が同じなら二重登録しない |
| 日付の区切り | 撮影日（0時で区切る） |

## 7. うまくいかないときの動き

| ケース | 動き |
|---|---|
| 位置情報がない写真 | 追加せず「〇枚は位置情報がないため追加できませんでした」と表示 |
| 地名が見つからない | 「見つかりませんでした。別の言い方で試してください」と表示 |
| 電波がない | 地図は表示されないことがある。保存済みの写真データは消えない |

## 8. 注意点

- 保存先は iPhone の Safari の中だけ。Safari の履歴・データを消すと、アプリのデータも消える。元の写真は写真アプリに残るので、選び直せば戻せる
- 保存できる枚数の上限は未確認。実際に使って確かめる
- iPhone で選んだ写真の位置情報が読めることは、Claude アプリ内で1枚だけ確認済み。本番の置き場所で、Safari から数枚で再確認する

## 9. 確認方法

1. パソコンで動作確認（位置・日時の読み取り、日付ごとのまとめ、重複判定）
2. iPhone の Safari で数枚の写真を追加して確認

## 10. 第2弾・第3弾の決めごと（2026-10-29 追記）

| 項目 | 決め方 |
|---|---|
| 移動距離 | その日の写真を時間順に、点と点をまっすぐ結んだ長さの合計（実際の道のりより短めに出る） |
| 距離の表示 | 10km 未満は小数1桁（例：3.2km）、10km 以上は整数（例：16km）。写真1枚の日は出さない |
| 時間の表示 | 最初と最後の撮影時刻（例：9:05〜17:40）。写真1枚の日はその時刻だけ |
| ▶再生ボタン | 写真が2枚以上の日を選んだときだけ出す。再生中は「■停止」になる |
| 再生の動き | 印がルートを1区間約1.2秒で進み、写真の場所に着くたびにその写真と撮影日時を約2秒出す |
| 再生の止まり方 | 最後の写真で終わる。■停止・別の日付・すべて・検索・写真追加でも止まる |
